## Kiến thức rút ra

### 1. Git căn bản
- Hiểu rõ Working Directory – Staging Area – Repository  
- Sử dụng thành thạo add, commit, status, log  
- Tạo nhánh, chuyển nhánh, làm việc tách biệt từng branch

### 2. Merging & Conflict
- Fast-forward merge và khi nào Git cho phép  
- 3-way merge khi branch bị phân nhánh  
- Cách đọc và xử lý merge conflict đúng quy trình

### 3. Rebase và lịch sử commit
- Tạo lịch sử tuyến tính bằng rebase  
- Rebase interactive để reorder, squash, fixup, drop  
- Autosquash để gom commit tự động

### 4. Quản lý lịch sử & phục hồi
- Amend để chỉnh sửa commit cuối  
- Reset (soft / mixed / hard) và sự khác nhau  
- Revert để hoàn tác thay đổi mà không phá lịch sử

### 5. Workflow thực tế
- Dọn workspace bằng git clean  
- Lưu tạm thay đổi bằng git stash  
- Kết nối và làm việc với remote repository
